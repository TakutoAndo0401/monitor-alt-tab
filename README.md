# Monitor Alt Tab

複数のモニターを使うときに、**マウスがある画面のウィンドウだけをAlt＋Tabで切り替える**Windows向けアプリです。

バージョン：0.1 ／ 対応環境：Windows 11（64ビット・x64）

## 起動する

1. ダウンロードしたZIPファイルを右クリックし、「すべて展開」を選びます。
2. 展開したフォルダーの **MonitorAltTab.exe** をダブルクリックします。

追加ソフトのインストールや管理者権限は不要です。設定画面を閉じてもアプリは動き続けます。Windows起動時の自動起動は行いません。

## 使い方

切り替えたいモニターにマウスを置いて操作します。

| 操作 | 動作 |
| --- | --- |
| Alt＋Tab | ウィンドウを選ぶ画面を表示 |
| Altを押したままTab | 次のウィンドウを選ぶ |
| Altを押したままShift＋Tab | 前のウィンドウを選ぶ |
| Altを離す | 選んだウィンドウに切り替える |
| Esc | キャンセル |
| Ctrl＋Alt＋F12 | 一時停止／再開 |

## 設定・終了する

画面右下の通知領域にあるアプリアイコンをダブルクリックすると、設定を開けます。見つからない場合は「隠れているインジケーターを表示（∧）」を開いてください。

設定では、対象モニターの選び方、見た目、プレビューの表示、切り替えの対象外にするアプリを変更できます。

アイコンを右クリックすると、一時停止や終了ができます。**終了すると、通常のAlt＋Tabに戻ります。** 設定はアプリと同じフォルダーの `settings.json` に保存されます。

## ご利用にあたって

- ブラウザーはウィンドウ単位で切り替えます。ブラウザー内のタブは対象外です。
- 全画面アプリの操作中は、初期設定で通常のAlt＋Tabを使います。
- 管理者として実行しているアプリなど、一部のウィンドウでは切り替えやプレビューができない場合があります。
- うまく動かない場合は一時停止するか、終了してから起動し直してください。
- このアプリには発行元を証明する電子署名を付けていません。

## プライバシー

アプリはインターネット通信を行いません。入力した文字の履歴やウィンドウの画像を保存・送信することもありません。ウィンドウ名やアプリ名は、切り替え画面の表示などにだけ使用します。
